## Exercicio 08: Otimização de cache layers
```bash
Você está construindo uma aplicação Python containerizada que possui dependências de produção e também dependências de desenvolvimento (para rodar testes).

Seu desafio é organizar o Dockerfile de forma que o cache seja reaproveitado ao máximo, evitando reinstalar pacotes desnecessários quando apenas o código muda.
```

```bash

docker-cache-tests/
├── Dockerfile.bad
├── Dockerfile.good
├── requirements.txt
├── dev-requirements.txt
├── app.py
└── test_app.py

```

**Aplicação Python**

```python
def soma(a, b):
    return a + b

if __name__ == "__main__":
    print("Resultado:", soma(2, 3))
```

**Aplicação test_app.py**

```python

import unittest
from app import soma

class TestApp(unittest.TestCase):
    def test_soma(self):
        self.assertEqual(soma(2, 3), 5)

if __name__ == "__main__":
    unittest.main()
```

**Requirements**

```
flask
```

**dev-requirements.txt**

```
pytest
coverage
```

**Dockerfile.bad**
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY . .
RUN pip install --upgrade pip && \
    pip install -r requirements.txt && \
    pip install -r dev-requirements.txt
CMD ["python", "app.py"]
```
*👉 Problema: qualquer alteração em app.py ou test_app.py invalida o cache e força reinstalação de todas as dependências.*

**Etapa 1**
```bash
1. Construa a imagem do Dockerfile.bad e Dockerfile.good
2. Rode a aplicação
3. Rode os testes
4. Acompanhe o Building 
```

**Etapa 2**

```bash
1. Realize alterações na aplicação app.py
2. Construa as imagens novamente
3. Acompanhe o Building e compare o tempo entre a primeira e segunda etapa
   e entre o Dockerfile.bad e Dockerfile.good
