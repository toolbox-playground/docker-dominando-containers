```bash
Imagine que você precisa rodar uma aplicação em Python que consome recursos de forma exagerada — simulando um processo mal comportado em produção.
Seu desafio é usar Docker para conter essa aplicação, aplicando limitações de memória, CPU e privilégios de segurança.
Você deve comparar a execução sem restrições e com restrições, observando como o Docker protege o host.
```
```

Você deve:

Construir uma imagem Docker para essa aplicação.

Rodar o container com e sem limitações de memória e CPU de 50%. 

Garantir que o container não rode como root.

Remover todas as capacidades extras do kernel para aumentar o isolamento.

Comparar a execução sem restrições e com restrições.

Monitore o consumo e verifique os logs.
```
