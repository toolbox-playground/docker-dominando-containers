# Exercício 6 - Múltiplos Estágios (Multi-stage)
```bash
Exercício Multi-Stage Build em Python

🎯 Objetivo
Criar três imagens Docker diferentes para uma aplicação simples em Python:

Slim – imagem única, sem multi-stage.

Build – primeira etapa do multi-stage, usada para instalar dependências e preparar o ambiente.

Runtime – segunda etapa do multi-stage, imagem final enxuta para rodar em produção.

O aluno deve comparar os tamanhos das imagens e entender por que o multi-stage é útil.
```
